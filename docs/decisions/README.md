# Architecture Decision Records (ADRs)

Decisões arquiteturais relevantes do GastroHub. Uma decisão aceita não é editada: quando muda, cria-se um novo ADR que a **substitui**, e o antigo é marcado como `Substituído por ADR-NNN`.

Status possíveis: `Proposto`, `Aceito`, `Rejeitado`, `Substituído por ADR-NNN`.

## Template

```markdown
# ADR-NNN — Título

- Status: Proposto
- Data: AAAA-MM-DD

## Contexto
## Problema
## Alternativas consideradas
## Decisão
## Consequências
```
